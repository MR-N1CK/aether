Coverage

Six places an intrusion hides.

Each pass is structural. Aether reads metadata, configuration, and file contents. It does not launch the file to see what it would do.

  1. 01

    Process

    Memory-only binaries, deleted executables still running, name masquerading, and hidden PIDs.

  2. 02

    Persistence

    systemd units, cron and at jobs, sudoers, shell profiles, and SSH authorized keys.

  3. 03

    Users

    Extra UID 0 accounts, duplicate UIDs, empty or obsolete password hashes, and privileged groups.

  4. 04

    Network

    Listeners mapped back to a process, raw sockets, and interfaces left in promiscuous mode.

  5. 05

    Kernel

    Loaded modules compared with sysfs, taint flags, and unexpected modprobe configuration.

  6. 06

    Files

    Unexpected SUID binaries, world-writable configuration, and scripts matched by heuristics or YARA-X.

A scan

Read, decide, explain.

01

Read

Files open with O_RDONLY, O_NOFOLLOW, O_NONBLOCK, and O_NOATIME when the kernel allows it. The scanner does not update mtime or ctime.

02

Decide

Pure-Go heuristics run in every build. The same embedded rules can be evaluated with YARA-X when you link it. Package databases catch replaced system binaries.

03

Explain

Each finding carries a title, why it matters, MITRE ATT&CK techniques, and containment steps. You can read that in the terminal, in JSON, or in one offline HTML file.

What you get

A dossier, not a raw log line.

This card uses the real copy registered for Linux_Backdoor_Reverse_Shell_OneLiner. The path is invented so the page can show the shape of a finding without pointing at a live host.

Start

Three commands, then look.

Build the pure-Go binary, check the engine, then open the command center. A full scan that writes an HTML report is the next line when you want a file you can hand to someone else.

git clone https://github.com/MR-N1CK/aether.git
cd aether
make build
./bin/aether doctor
sudo ./bin/aether
sudo ./bin/aether scan --quick --plain --html-out report.html

Limits

What a clean run does not prove.

  • Without root, Aether cannot read /etc/shadow, root cron spools, or other users’ /proc entries. The report says so.
  • Analysis is static. Packed binaries are not emulated.
  • A rootkit that unlinks itself from both /proc/modules and sysfs needs a memory image, not this scanner.
  • Files larger than 50 MB are recorded and skipped for hashing and YARA, unless you raise --max-filesize.
  • Rule updates and an intel URL are the only networked actions, and only when you ask for them.
