Surface Inspection

Six areas an intrusion cannot hide.

Each audit pass is strictly structural. Aether statically reads kernel structures, memory descriptors, configuration trees, and file bytes using safeopen without executing code.

01

Process Forensics

Unlinks, memory-only execution (/memfd:), deleted binaries, comm/cmdline masquerading, and two-pass hidden PID discovery.

02

Persistence Hunter

Audits systemd units, masked services, cron, at spools, sudoers drop-ins, PAM execution modules, and SSH authorized keys.

03

Accounts & Privilege

Flags rogue UID 0 clones, duplicate UIDs, legacy or empty shadow hashes, passwordless accounts, and docker/lxd privilege escalation.

04

Network Sockets

Correlates socket inodes back to process trees, maps unmapped wildcard listeners, catches raw packet consumers, and promiscuous sniffers.

05

Kernel Integrity

Cross-references /proc/modules with sysfs driver trees to reveal hidden LKM rootkits, tainted flags, and modprobe overrides.

06

Binary & Script Scanner

Static ELF behavioral analysis, recursive deobfuscation (base64, hex, rot13, shell dequoting), and static YARA-X compiled rules.

Architecture Pipeline

Read, decide, and explain.

Phase 01

Read-Only Invariant

Opens files using O_RDONLY | O_NOFOLLOW | O_NONBLOCK | O_NOATIME via safeopen primitives. Guarantees zero forensic contamination and zero timestamp mutation.

Phase 02

Dual-Engine Decision

Runs native Go regex heuristics alongside compiled static YARA-X rules. Multi-distro package grounding (dpkg, rpm, pacman, apk) eliminates false positives on system tools.

Phase 03

MITRE ATT&CK Enrichment

Enriches every finding with a plain-English explanation, threat score (0–100), MITRE tactic and technique mapping, and copyable containment commands.

Quickstart

Deploy in under 10 seconds.

Single statically compiled binary with zero external runtime dependencies. Point it at any Linux target or root filesystem mount.

BASH TERMINAL 
# 1. Clone repository and build pure-Go binary
git clone https://github.com/MR-N1CK/aether.git
cd aether && make build

# 2. Run system diagnostic and launch Flight Deck TUI
./bin/aether doctor
sudo ./bin/aether

# 3. Export standalone forensic HTML report
sudo ./bin/aether scan --quick --plain --html-out report.html
